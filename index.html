EzyForms — hospitality workflow application

EzyForms is a paperless hospitality workflow application for centralized form management, quick approvals, and audit-ready record keeping across properties. It covers business unit setup, employee and admin management, dynamic approval workflows, and several operational modules.

Full feature list
  • Aadhaar masking — identification fields flagged "Is secure" show only the last 4 digits.
  • Dynamic HOD-based approvals — approvers resolve from a department's configured HOD at request time, not hardcoded per form.
  • Save as draft — forms can be saved mid-fill and resumed later from My Requests.
  • Approve/reject via email, no login — approvers act straight from an email action button.
  • Admin password reset — force-resets any employee's password with a unique temporary password by email.
  • Interactive dashboard — a "My Approvals" widget plus clickable charts/tiles that deep-link into filtered lists.
  • No-role-assigned safeguard — flags unroutable requests instead of leaving them stuck; only an admin can cancel them.
  • Tiered password policy — Fair / Strong / Very Strong enforcement presets.
  • Ad-hoc reports & charts — build a filtered report or chart for any form, export to Excel/CSV.

Audit Module

Audit is a module within the EzyForms (ezy_forms) Frappe app, adding a rule-based workflow engine and bulk data ingestion (CSV/Excel/JSON) on top of dynamically generated form doctypes. Built the engine that evaluates records against configurable conditions and auto-raises multi-level requestor → approver requests when a rule matches, plus dashboards and rule-wise approval tracking.

Full feature list
  • Rule engine — evaluates records against per-rule AND-grouped conditions; the first matching rule auto-raises its approval.
  • Bulk data ingestion — CSV/Excel/JSON import via Frappe's Data Import tool, with automatic date-format normalization.
  • Per-rule approval routing — different conditions on the same form can route to different approver chains.
  • Rule-wise dashboards — assigned/approved/pending breakdowns, with configurable column layouts per rule.

05 / Professional project · CaratRED Technologies LLP

HardWare BU — trading mini-ERP (hardwarebu)

HardWare BU is a standalone Frappe app implementing a minimal mini-ERP for CaratRED's Hardware Business Unit — back-to-back customer/vendor purchase orders, payment reconciliation against a bank ledger, and gross-margin reporting. It's fully independent of ERPNext and the other CaratRED apps, with no stock/warehouse or asset-tracking concepts.

Full feature list
  • Back-to-back trading model — a Customer Order can link directly to the Vendor Order purchased specifically to fulfill it.
  • Bank ledger reconciliation — every payment and expense reconciles against a Bank Transactions ledger (Debit/Credit per account).
  • Auto status lifecycle — orders move Pending → In Progress → Closed based on payments received/paid, then lock read-only.
  • GST & discount validation — validates item totals against PO value and computes GST difference and discount amounts on save.
  • Gross-margin reporting — joins a closed Customer Order's items against its linked Vendor Order to compute price difference, margin, and margin % per item or per order.
  • Expense tracking — internal, customer-associated, and vendor-associated expenses, also reconciled to the bank ledger.

Homaso.
06 / Professional project · CaratRED Technologies LLP

Homaso — hostel/PG management system

Homaso is a hostel/PG management system: a Frappe backend plus a standalone Vue 3 PWA frontend covering the full tenancy lifecycle — properties, rooms and beds, tenant onboarding, leases with recurring rent/GST billing, online self-service booking, and exit settlement. The Vue app talks to Frappe entirely through whitelisted REST endpoints, with multi-hostel data isolation enforced via native Frappe User Permissions.

Full feature list
  • Full lease lifecycle — booking → lease → recurring rent/GST billing → mid-lease updates → exit clearance, each with its own submittable doctype and workflow.
  • Online self-service booking — a public web form with QR-code self-check-in that auto-creates the tenant and booking records.
  • Automated daily billing — cron jobs generate each period's rent, cascade room-rate changes, and apply approved lease updates.
  • Multi-hostel data isolation — Supervisors/Employees get scoped Frappe User Permissions (by Hostel/Region) generated automatically on creation.
  • Vue 3 PWA frontend — an installable app (Vite + Pinia + Tailwind) covering dashboard, bookings, leases, payments, and reports, calling ~96 whitelisted API functions.
  • Reporting suite — 11 reports covering occupancy, dues, collections, and revenue.
